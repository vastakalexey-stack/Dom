# Домик

Android-приложение для просмотра видеопотоков домофона Дом.ру и камеры Xiaomi, а также управления открытием двери.

## Структура
- `app/` — Android-приложение на Kotlin и Jetpack Compose.
- `app/src/main/java/com/example/intercom/` — исходный код.
- `app/src/main/res/` — ресурсы Android.

## Сборка
Откройте репозиторий в Android Studio с Android SDK 35 и JDK 17. Для сборки требуется Gradle 8.9 или совместимый wrapper.

## Важно
Приложение использует API Дом.ру и требует действующей авторизации. Команда открытия двери выполняет реальное действие; проверяйте подключённый аккаунт и адрес перед использованием.
